# Fotos oficiais do Hotel Triunfo

Coloque aqui **somente fotografias reais do hotel**. O nome do arquivo precisa
ser exatamente o listado em `src/data/photos.ts` (galeria e destaques) ou em
`src/data/rooms.ts` (fotos de cada acomodação).

| Arquivo                 | Onde aparece                              |
| ----------------------- | ----------------------------------------- |
| `hero.jpg`              | Fundo da primeira dobra (fachada/recepção) |
| `sobre.jpg`             | Seção "Nossa história"                    |
| `fachada-01.jpg`        | Galeria — Fachada                         |
| `recepcao-01.jpg`       | Galeria — Recepção                        |
| `quarto-01.jpg`, `quarto-02.jpg` | Galeria — Quartos                |
| `banheiro-01.jpg`       | Galeria — Banheiros                       |
| `cafe-01.jpg`           | Galeria — Café da manhã                   |
| `estacionamento-01.jpg` | Galeria — Estacionamento                  |
| `areas-comuns-01.jpg`   | Galeria — Áreas comuns                    |

Recomendações: JPG de boa qualidade, 1600 px ou mais no lado maior, sem marca
d'água. O build gera versões AVIF/WebP redimensionadas automaticamente.
Para adicionar mais fotos, inclua novas entradas em `src/data/photos.ts`.
