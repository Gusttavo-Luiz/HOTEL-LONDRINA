# Fotos oficiais do Hotel Triunfo

Coloque aqui **somente fotografias reais do hotel**, com o nome exato
listado abaixo (ou em `src/content/gallery.ts` e `src/content/rooms.ts`).
JPG de boa qualidade, 1600 px ou mais no lado maior, sem marca d'água.
O build gera AVIF/WebP redimensionados automaticamente.

| Arquivo | Onde aparece |
| --- | --- |
| `hero.jpg` | Primeira dobra (fachada ou acomodação) |
| `sobre-01.jpg`, `sobre-02.jpg` | Seção "Sobre o Hotel" |
| `fachada-01.jpg` | Galeria — Fachada |
| `recepcao-01.jpg` | Galeria — Recepção |
| `quarto-01.jpg`, `quarto-02.jpg` | Galeria — Quartos |
| `cafe-01.jpg` | Galeria — Café da manhã |
| `areas-comuns-01.jpg` | Galeria — Áreas comuns |
| `garagem-01.jpg` | Galeria — Garagem |
| `quarto-*-01.jpg` | Cards de acomodações (ver `rooms.ts`) |

Para mais fotos, adicione entradas em `src/content/gallery.ts`.
